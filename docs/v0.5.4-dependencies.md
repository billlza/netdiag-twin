## 必须保留的上游约束

最新稳定 linfa 0.8.1/linfa-logistic 0.8.1 与 axum 0.8.9 仍有以下约束；没有
通过不安全强转、修改模型算法或自行放宽上游 manifest 来绕开它们。

| 依赖 | 使用版本 | 上游最新稳定版 | 当前约束 |
| --- | --- | --- | --- |
| ndarray | 0.16.1 | 0.17.2 | linfa/linfa-logistic 的公开数组与 Dataset 类型要求 `^0.16`。 |
| sprs | 0.11.2 | 0.11.5 | linfa 0.8.1 精确要求 `=0.11.2`。 |
| matchit | 0.8.4 | 0.8.6 | axum 0.8.9 精确要求 `=0.8.4`；来自 tonic 服务端依赖链。 |

`cargo update --locked --verbose` 明确列出这三项未升级。其他不同主版本的传递依赖
也可能因上游范围而共存；已用 Cargo metadata 逐条核对直接父依赖和版本约束。
`deny.toml` 只更新这些有依据的精确版本例外，`multiple-versions=deny`、来源限制、
受影响的 OpenTelemetry SDK 禁用范围和零 advisory waiver 要求均保留。

serde_yaml 的最新已发布版本仍是 `0.9.34+deprecated`；当前使用这一版本，不将其
描述为仍在积极维护。替换 YAML 实现需独立验证现有场景/策略文件语义和错误行为。

## 安全补丁与兼容迁移

- [wayland-scanner 0.31.11](https://crates.io/crates/wayland-scanner/0.31.11) 已要求
  quick-xml `^0.41`，满足旧补丁的移除条件。删除 0.31.10 本地补丁，保留面向上游
  发布版本的 XML 1.0/生成接口可执行契约。旧补丁另存本地验证目录，Git 历史仍保留原始来源与许可证。
- argmin 最新稳定版仍为 0.11.0，尚未消除普通依赖中的 paste。现有、带完整来源
  校验的 argmin 补丁和回归契约继续保留。
- SHA-2 0.11 的输出数组不再提供旧的 `LowerHex` 接口；改为共用明确的逐字节
  小写十六进制编码，保留既有磁盘哈希格式，并加入 SHA-256 已知向量验证。
- muda 0.20 的快捷键修饰键参数改为直接 `Modifiers`；迁移两处原生菜单构造，
  保留 Command/Control 和 Shift 的原有组合。
